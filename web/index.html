    Upload from
    your terminal.

    Plain curl, nothing to install.

    1Send a file
    $ curl{{curl_token}} --upload-file ./photo.jpg {{origin}}/photo.jpg
    Prints the link. That's it.
    2Add limits
    $ curl{{curl_token}} -H "Max-Days: 1" -H "Max-Downloads: 1" --upload-file ./secret.zip {{origin}}/secret.zip
    Expires after 1 day and burns after the first download.
    3Forgot the token?
    $ curl --upload-file ./photo.jpg {{origin}}/photo.jpg
Error: this server requires an upload token.
    The server answers 401 and shows the right command. 5 wrong tokens lock your IP for a while.

    More examples

    $ tar czf - ./project | curl{{curl_token}} --upload-file - {{origin}}/project.tar.gz
    Pipe from stdin 
    $ curl -u :YOUR_TOKEN --upload-file ./photo.jpg {{origin}}/photo.jpg
    Shorter token form 
    $ curl -X DELETE {{origin}}/abc/photo.jpg/<delete-token>
    Delete early 
    $ eval "$(curl -fsSL {{origin}}/install.sh)" && fsend{{token}} ./photo.jpg
    Optional shell helper

    Options

    --oauth2-bearer <token>Your upload token. curl has no --token flag; this is its built-in equivalent.
    -H "Max-Days: N"Expire after N days. Decimals allowed: 0.5 = 12 hours. Default 3, max 30.
    -H "Max-Downloads: N"Delete after N downloads.
    -u :<token>Same as --oauth2-bearer, shorter to type.

    What you get back

    Body
    {{origin}}/abc/photo.jpg
    X-Url-Delete
    {{origin}}/abc/photo.jpg/<token>
    X-Expires-At
    unix time, e.g. 1793861549
